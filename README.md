# GitHub Copilot 中級編

GitHub CopilotのCustom Instructions、Custom Agents、Skillsを、要件定義からシステムテストまでのV字モデル開発へ適用するハンズオン教材です。

受講者は各工程に適したAgentとSkillを自分で定義し、既存の開発資料やコードを参照しながら、設計・実装・テストで実際に活用します。さらに、GitHub Cloud Agentへの作業委譲やCopilot Code Reviewによる変更確認を通じて、人が計画・判断し、AI Agentが作業を進めるAgenticな開発を実践します。

## このハンズオンで得られること

- Custom Instructionsでリポジトリ共通のルールを与える方法
- 工程ごとにCustom Agentの役割、モデル、ツール、担当範囲を設計する方法
- 再利用できる作業手順や判断基準をSkillとして定義する方法
- AgentとSkillをV字モデルの成果物へ適用し、工程間の対応を保つ考え方
- 計画と作業範囲を明確にしてGitHub Cloud Agentへ実装を委譲する方法
- Copilot Code Reviewを活用し、AI Agentが作成した変更を人が確認・判断する進め方
