# コーディング規約

| ID | 規約 | レビュー時の観点 |
|---|---|---|
| C1 | 外部入力は型検査だけでなく実行時に検証する | body、path、queryの型ガード、不正値の応答 |
| C2 | 状態変更は検証後に行い、拒否時は元のデータを維持する | 全遷移、飛び越し、逆戻り、同一状態 |
| C3 | エラーはJSON形式と適切なHTTPステータスで返す | 400/404/409とパーサーエラー。内部スタックを応答しない |
| C4 | 既存の振る舞いを維持し、変更にはテストを付ける | `app` export、health test、R1〜R6の追跡 |
| C5 | 承認されたUI・APIの範囲で変更し、不要な依存・機能追加をしない | 画面は既存Expressで配信し、無断のUIフレームワーク・認証・DB追加をしない |
| C6 | 失敗・未実行を成功と記録しない | コマンド、終了コード、対象SHA、未解決事項 |
| C7 | クラス名と型名はPascalCase、変数・関数・メソッド・プロパティ名はcamelCaseとする | 新しく追加した識別子の命名規則 |
