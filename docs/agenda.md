# アジェンダ

## 実践（3時間）

受講者は、短納期の追加開発を任された既存開発チームの一員として、各工程のハーネスを制作し、その工程で使用します。作業計画はハーネスを指定したCopilot appのPlanから始め、承認済み計画と資料をGitHub Cloud Agentへ明示的に渡します。

### 01 始める前に

- 対象者
- 前提環境
- 短納期の追加開発と、既存開発プロセスへのAI適用
- 題材システムの概要と現行仕様

### 02 共通設定

- 既存の開発規約とCustom Instructions

### 03 要件定義

- 要件定義用Agent／Skill／Prompt
- ハーネスを適用したPlanと要件定義

### 04 基本・詳細設計

- 設計用Agent／Skill／Prompt
- 設計ハーネスを適用したPlanとCloud Agentによる基本設計・詳細設計

### 05 実装・レビュー

- 実装用Agent／Skill／Prompt
- 実装ハーネスを適用したPlanと機能の追加開発
- コーディング規約に基づくレビューSkill／Custom Instructions
- Copilot Code Reviewによる変更差分のレビュー

### 06 テスト

- UT／IT／STそれぞれの専用Agent・専用Skill
- 必要に応じたPrompt・Instructionsと共通の証跡Skill
- 変更差分に対応するテスト、回帰テスト、テスト証跡

### 07 まとめ

- まとめ用Agent・Skillの制作と適用
- 開発結果とハーネスの有効性
- 現行プロジェクトでの活用上の課題と、持ち帰る成果物

### 時間配分の扱い

提示された図には時間がないため、前案の時間枠を以下のように引き継ぎます。**02と03は別アジェンダとし、合計25分の内訳は未確定**です。各セクションの詳細確認時に決定します。

| 区分 | 時間 | 扱い |
|---|---:|---|
| 01 始める前に | 10分 | 対象者・前提環境、背景・題材説明 |
| 02 共通設定 ＋ 03 要件定義 | 25分 | 02・03の個別配分は未確定 |
| 04 基本・詳細設計 | 35分 | 前案から継続 |
| 05 実装・レビュー | 75分 | 前案の実装55分とレビュー20分を合算 |
| 06 テスト | 25分 | 前案から継続 |
| 07 まとめ | 10分 | 前案から継続 |

実践は合計180分です。修正は不具合・要件逸脱等が見つかった場合の分岐であり、必ず修正が発生する前提にはしません。本人の発表を必須課題にはしません。MCPは座学の説明・静的なツール定義例で扱い、実接続を伴う必須演習には含めません。

各工程では、[ドキュメント項目定義](document-items.md)と工程別の要件・設計・テスト資料を参照します。受講者は既存資料とコードを入力として、工程に対応するAgentとSkillを作成・適用します。
